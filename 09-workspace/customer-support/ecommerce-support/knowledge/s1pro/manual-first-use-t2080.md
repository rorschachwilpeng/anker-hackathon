# eufy Robot Vacuum Omni S1 Pro（T2080）首次使用

本资料仅适用于订单商品型号为 T2080 的 eufy Robot Vacuum Omni S1 Pro 扫地机器人。官方快速入门指南给出的首次设置要点如下：

1. 将 Uniclean™ Station 放在靠墙的坚硬平整地面，前方留出约 1.5 米、两侧留出约 0.5 米空间，并选择 Wi-Fi 信号较强的位置。
2. 使用前移除机器人和基站上的泡沫包装、贴纸及额外滚筒拖布；按标记安装侧刷，红色 1 号和灰色 2 号不要装反。
3. 清水箱加清水至 MAX 线后装回；不要向清水箱加入第三方消毒剂或清洁剂。硬地板清洁剂只使用 eufy 指定产品。
4. 基站接通电源，打开机器人磁吸盖并将电源开关拨至“I”；对齐充电触点，将机器人放到基站开始充电。
5. 如需使用 App，按住机器人 Reset 键 1 秒启动 Wi-Fi 连接，再按 App 内指引完成配对；设备仅支持 2.4 GHz Wi-Fi。
6. 在新环境首次使用时，机器人会进行建图。建图期间建议打开家中所有房门并清除地面障碍物；官方建议先使用纯吸尘模式 1 至 3 次，再使用吸拖模式。

若实际机身、基站或 App 与指南图示不一致，应以随附的 T2080 用户指南和 eufy 官方支持为准。不要把其他品类 S1 Pro 的说明套用到本型号。
