## 产品识别

### eufyMake E1 是什么产品？

eufyMake E1 是 UV 打印设备。查询耗材、打印头、附件、维护和保修时应明确使用 UV Printer E1 产品名；打印头、耗材和主机适用不同的退换与保修条件。

## X 轴皮带排查

<!-- key-clause -->
### E1 打印图案错位或断色，怎样检查 X 轴同步带？

图案错位、重叠或断色且初步判断为 X 轴同步带松动时，先停止打印并移除打印头上方面板，轻压 X 轴同步带检查松弛程度。该操作需要用户自备 2mm 内六角扳手，并应严格按官方步骤执行。
资料标记：产品 UV Printer E1；[eufyMake 官方维修指南](https://support.eufymake.com/s/article/eufyMake-E1-X-axis-Timing-Belt-Tension-Adjustment-Guide)；采集于 2026-09-26。

### E1 怎样调整 X 轴同步带张力？

使用 2mm 内六角扳手逆时针松开自动张紧模块螺丝约三圈，不要完全拆下螺丝。弹簧会推动张力滑块自动调整位置；完成后顺时针拧紧螺丝锁定新位置。操作没有把握、设备仍异常或涉及其他组件时，应停止自行处理并联系 eufyMake 支持。
资料标记：产品 UV Printer E1；[eufyMake 官方维修指南](https://support.eufymake.com/s/article/eufyMake-E1-X-axis-Timing-Belt-Tension-Adjustment-Guide)；采集于 2026-09-26。

## 安全边界

### E1 维修时可以自行拆卸其他组件吗？

知识库只覆盖官方公开的 X 轴同步带张力调整步骤。打印头、电气部件和未在官方用户维护指南中列出的组件，应交由官方支持判断；自行拆卸可能影响设备和保修处理。
资料标记：产品 UV Printer E1；[eufyMake 官方维修指南](https://support.eufymake.com/s/article/eufyMake-E1-X-axis-Timing-Belt-Tension-Adjustment-Guide)；采集于 2026-09-26。
